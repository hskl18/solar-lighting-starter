# Asset Provenance

Every image shipped with this starter is an original SVG composition authored specifically for this learning project.
No third-party photos, logos, icons, fonts, or traced artwork are included.
The SVG files use simple shapes, paths, and gradients that can be inspected in a text editor.

## Adding an asset

Add only work you created, public-domain material with a verified source, or material whose license permits this repository's commercial and educational reuse.
Record the filename, creator or source, source URL when applicable, and license in this document.
Do not assume that an image is reusable only because it is visible on the public web.
Remove embedded authoring metadata or private information before committing an exported file.
